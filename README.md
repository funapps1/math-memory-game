# Math Memory Game

Simple browser-based memory game matching math expressions to their values.

Features:
- Configurable grid size (4×4, 6×6)
- Choose addition, subtraction, or both
- Configure tile size (px)
- Move counter and 3-star rating
- Voice encouragement using the Web Speech API (can mute)

To run: open `index.html` in a browser (no server needed).
